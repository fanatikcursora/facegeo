# FaceGeo — оценка лица по замерам

Сайт считает пропорции, углы, симметрию, размеры в миллиметрах и состояние кожи
по фото анфас (и, по желанию, в профиль) и выдаёт балл PSL от 0 до 8 с тиром:
Sub 3, Sub 5, LLTN / MLTN / HLTN, LMTN / MMTN / HMTN, LHTN / MHTN / HHTN,
Chadlite, Chad, Gigachad (для женского пола — LTB / MTB / HTB, Stacylite, Stacy).

Всё считается в браузере. Фото никуда не отправляются: с интернета загружаются
только модели MediaPipe (сетка лица и сегментация).

## Запуск

Двойной щелчок по `start.bat` (нужен Python). Или вручную из этой папки:

```bash
python -m http.server 5173
```

и открыть http://localhost:5173.

## Что где лежит

| Файл | Что делает |
|---|---|
| `js/config.js` | **Все числа**: тиры, веса категорий, идеалы и допуски замеров, калибровка PSL |
| `js/frontal.js` | Замеры анфас по 478 точкам MediaPipe: фронтализация, масштаб по радужке, отношения и углы |
| `js/skin.js` | Кожа (высыпания, тон, текстура) и чёткость линии челюсти — по пикселям |
| `js/profile-auto.js` | Авторазметка профиля по контуру лица |
| `js/profile.js` | Точки профиля и углы по ним |
| `js/scoring.js` | Замер → балл → категория → PSL → тир |
| `js/app.js` | Интерфейс |

## Как считается оценка

1. **Точки.** MediaPipe Face Landmarker ставит 478 точек. По ним строятся оси
   лица, и координаты пересчитываются так, будто голова смотрит ровно в камеру.
2. **Миллиметры.** Диаметр радужки у людей почти одинаков (11.7 мм) — это линейка.
3. **Замеры** по категориям:
   - *Гармония*: мидфейс, трети лица, пропорция нижней трети, подбородок / фильтрум,
     расстояние между глазами (ESR), ширина / высота лица, асимметрия.
   - *Диморфизм*: FWHR, челюсть / скулы, посадка бровей (расстояние бровь–веко),
     полнота губ, ширина подбородка / рта.
   - *Ангулярность*: чёткость линии челюсти (по тени под ней), фронтальный угол
     челюсти, выраженность угла челюсти.
   - *Фичи*: кантальный тилт (наклон глаз), размер и разрез глаз, наклон бровей,
     рот / нос, нос / межкантальное, нижняя / верхняя губа.
   - *Костная масса*: ширина скул, челюсти, подбородка и высота лица в мм.
   - *Кожа*: доля площади под высыпаниями и пятнами, неровность тона, текстура.
   - *Профиль*: носолобный, носогубный, губо-подбородочный углы, выпуклость
     профиля, губы относительно E-линии, гониальный угол (после ручной правки точек).
4. **Балл замера**: 100% внутри идеального диапазона, 50% при отклонении на допуск,
   20% при двух допусках.
5. **Итог**: взвешенное среднее категорий, плюс 10% веса у четырёх худших замеров
   («фейло»).
6. **PSL**: итог сравнивается со средним человеком из калибровочной выборки.
   Средний получает 4.1 (MMTN), каждое стандартное отклонение — ±0.77.

## На чём откалибровано

102 нейтральных фото (53 мужчины, 49 женщин) из открытого набора
**Face Research Lab London Set** — DeBruine, L. & Jones, B. (2017), CC-BY,
doi:10.6084/m9.figshare.5047666. У каждого лица в наборе есть средняя оценка
привлекательности от 2513 человек.

- Допуски равны разбросу каждого замера в этой выборке.
- Идеалы стоят рядом со средним и сдвинуты туда, куда указывают оценки людей;
  где данные молчат — туда, куда указывают луксмакс-гайды и антропометрия.
- Итоговый балл совпадает с оценками людей с корреляцией **r ≈ 0.43 у мужчин и
  r ≈ 0.70 у женщин**. Это проверка на тех же лицах, по которым шла подгонка,
  поэтому на новых фото совпадение будет слабее.
- В выборке тиры распределились так (мужчины): Sub 5 — 9%, LTN — 23%, MTN — 42%,
  HTN — 21%, Chadlite — 6%, Chad и выше — никого.

## Чего сайт не умеет

- Это формулы, а не истина. Одно лицо на разных фото даст разные цифры:
  влияют ракурс, расстояние до камеры, объектив, свет и мимика.
- Выборка — студийные фото при одном свете. Телефонное фото с фильтром,
  шумом или резкостью сдвинет оценку кожи.
- Верхняя треть лица не меряется: линию волос сетка не видит.
- «Костная масса» — это ширина лица вместе с мягкими тканями: кость от полноты
  на фото анфас не отделить.
- Угол челюсти в профиль по контуру не виден. Точки Go и Tr надо ставить
  руками; пока их не тронули, гониальный угол в оценку не входит.
- Сетка лица сглаживает контур, поэтому углы челюсти в анфас меняются от лица
  к лицу слабо и весят мало.
- Фото с поворотом головы больше 15° не принимаются.
